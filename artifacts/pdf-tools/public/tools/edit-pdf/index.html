Frequently asked questions

  • What kind of edits are supported?

    The current client-side workflow supports local page-level edits and prepared PDFium compatibility checks for advanced object-level editing.

  • Does this upload my file to a server?

    No. The edit flow is implemented as a browser-side proof of concept and keeps the file on your device while it is processed.

  • Will edit-pdf preserve my file's formatting and quality?

    Results depend on the source file and the operation. Review the downloaded result before relying on it, especially for complex layouts, scanned pages, or image-heavy documents.

  • Can I use edit-pdf for free?

    Yes. PDFKira currently offers its core tools free to use, with no account required for this workflow.

  • Do I need to install software to use edit-pdf?

    No. You can use this online tool in a current web browser without installing a separate desktop application.
