Split PDF

Break a PDF into separate files or page ranges.

How it works

  1. Upload the PDF you want to split.
  2. Choose how to split it: by page ranges or every page separately.
  3. Click Split and download your new files.

    Open this page in your browser, provide the file or information requested, choose any available options, then start the task and save the result.

  • Do I need to install software to use Split PDF?

    No. You can use this online tool in a current web browser without installing a separate desktop application.
