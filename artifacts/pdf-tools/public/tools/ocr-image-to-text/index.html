Extract editable text from images and scanned PDFs.

How it works

  1. Upload an image or scanned PDF.
  2. Wait while the document is processed with OCR.
  3. Edit, copy, or download the extracted text.

Frequently asked questions

  • What is OCR?

    OCR (Optical Character Recognition) converts images of text into editable, searchable text.

  • Does OCR support Nepali?

    Yes — this tool supports English and Nepali recognition (eng+nep) using Tesseract.

  • Can OCR read handwritten notes?

    Handwritten text has mixed results; clear printed text or high-quality scans work best.

  • Does OCR work on scanned PDFs?

    Yes. Upload a scanned PDF and we convert pages to images before running OCR.

  • Is my uploaded file private?

    Files are processed temporarily and removed from our servers shortly after processing.
