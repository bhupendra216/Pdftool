Add Background

Remove the existing background and add a new background to your image.

How it works

  1. Upload an image with the background you want to replace.
  2. Choose a transparent, solid-color, or custom background.
  3. Download the finished image as a PNG or JPG.

Frequently asked questions

  • Are there file size or page limits for add-background?

    Limits vary by tool and file type. Check the upload controls for the current file-size or page limit before starting; large or complex files may take longer.

  • Does this run in my browser?

    Yes. The foreground is extracted locally in your browser, then composited onto the new background you choose.

  • What output formats are available?

    PNG is always available. JPG is available whenever the chosen background is not transparent.

  • Can I use add-background for free?

    Yes. PDFKira currently offers its core tools free to use, with no account required for this workflow.

  • Do I need to install software to use add-background?

    No. You can use this online tool in a current web browser without installing a separate desktop application.
