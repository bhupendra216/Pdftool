# OG Image Instructions

PDFKira social sharing assets should be generated in 1200x630 format as JPG or PNG files.

## Folder pattern

The images are expected to live in the `public/og-images/` folder and use the naming convention below.

## Required files

- merge-pdf.jpg
- split-pdf.jpg
- compress-pdf.jpg
- pdf-to-word.jpg
- word-to-pdf.jpg
- pdf-to-excel.jpg
- excel-to-pdf.jpg
- pdf-to-powerpoint.jpg
- powerpoint-to-pdf.jpg
- pdf-to-images.jpg
- images-to-pdf.jpg
- pdf-to-text.jpg
- ocr-pdf.jpg
- rotate-pdf.jpg
- reorder-pages.jpg
- add-watermark.jpg
- protect-pdf.jpg
- unlock-pdf.jpg
- sign-pdf.jpg
- flatten-pdf.jpg
- pdf-to-pdfa.jpg
- compress-images.jpg

## Design template

- PDFKira logo top-left
- Tool name in large bold text centered
- “100% Free • No Signup • No Ads” badge at the bottom
- Clean blue/purple gradient background
- Subtle PDF illustration or icon overlay

This keeps each tool page shareable and consistent with Google and social platform expectations.
