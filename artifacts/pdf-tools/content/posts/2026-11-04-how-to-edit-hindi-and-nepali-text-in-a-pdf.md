# How to Edit Hindi and Nepali Text in a PDF

## Start with selectable Devanagari text

Edit PDF works with real, selectable Hindi and Nepali text in a PDF. Select existing text to edit it, or add a text box for new content. If the characters are already damaged or missing, you may need to retype them. Open [Edit PDF](tool:edit-pdf) to check a copy of your document.

## Choose a Devanagari font

For Devanagari text, choose Noto Sans Devanagari, Noto Serif Devanagari, or Mukta in the text controls. Review the rendered text and downloaded file: PDF font mappings and page layout can vary from one source document to another.

## Type with your keyboard or phonetic input

You can enter text with your device keyboard. Edit PDF also offers phonetic typing: type Latin letters and the editor converts recognized sequences into Devanagari. For example, `namaste` becomes `नमस्ते`, and `nepal` becomes `नेपाल`.

## Know the limits before editing

Scanned pages contain images rather than selectable text, so run OCR first with [OCR PDF](tool:ocr-pdf) and check its available language choices before using the result in Edit PDF. A PDF made with a legacy font such as Preeti or Kantipur may not map to Unicode and may show unreadable characters. Some damaged text must be retyped. Review the output against the original before sharing it.
